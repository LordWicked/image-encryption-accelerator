# Project

In the project, students will propose, design, develop, test, optimize, revise, document, and present a Chisel generator. The project's target application should contain some opportunities for parameterization and hardware generation as well as be of a reasonable scope.

- What does your generator do and what is it for? (application)
- What sort of interfaces does it have?
- What parameters does it take?
- How does it work under the hood?
- How did you incrementally develop it?
- Project completeness (functionality, testing, documentation, etc…)

Time permitting:

- Any interesting uses of inheritance or functional programming?
- Things you learned along the way
- Advice for future students of the course
