# Project Management
## Scrum masters log
MD file with 1 line per week, identifying which student plays the role of scrum master in that week.

## Work breakdown structure
Spreadsheet with the work breakdown structure of your project. 
Each page in the spreadsheet should represent the list of tasks valid on a given week, as some tasks might be added 
or removed at any time.

## Sprints info

Each week corresponds to a sprint. For each sprint, we'll store the following information:
- BurndownChart (spreadsheet) - The spreadsheet is going to identify the status per day along the week.
- Screenshots of the scrum board during that week - Identifying which tasks were made by who with the corresponding reviewers.
- Gant Chart
